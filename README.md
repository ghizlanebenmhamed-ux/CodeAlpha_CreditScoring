# Credit Scoring Model

A credit risk classification project developed for CodeAlpha’s Machine Learning internship.

## Features

- Load a test sample or enter applicant data
- Predict good or bad credit risk
- Display the model score for bad credit risk
- View evaluation metrics and the confusion matrix

## Dataset and model

The project uses the German Credit dataset and Logistic Regression.

The dataset is split into 800 training samples and 200 test samples. Model performance is evaluated on the held-out test set.

## Technologies

Python, Tkinter, and scikit-learn.

## How to run

4. On Windows, double-click START_WINDOWS.bat.
5. Load a sample and click Predict credit risk.

## Evaluation

The application reports accuracy, precision, recall, F1-score, ROC-AUC, and a confusion matrix. Bad credit risk is the positive class.

## Limitations

This is an educational project using historical data. Predictions are not bank credit ratings or lending decisions, and the model can make mistakes.
